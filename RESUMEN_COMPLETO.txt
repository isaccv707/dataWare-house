🎯 PROYECTO: Predicción de Éxito de Productos en Amazon

═══════════════════════════════════════════════════════════════

PASO 1: INSTALAR REQUISITOS
   • Python 3.8+ (https://python.org/downloads)
   • Docker Desktop (https://docker.com/products/docker-desktop)
   ⚠️ IMPORTANTE: Marca "Add Python to PATH" al instalar

PASO 2: CONFIGURACIÓN (Una sola vez)

   Esto instala:
   ✓ Dependencias Python
   ✓ Base de datos PostgreSQL
   ✓ Modelos de Machine Learning
   ✓ Todo lo necesario

PASO 3: EJECUTAR
   Windows: Doble clic → RUN.bat
   Linux/Mac: ./run.sh
   
   Elige:
   1 = Predictor de Productos (con reseñas)
   2 = Asesor de Emprendedores (sin reseñas)
   3 = Ambas aplicaciones

═══════════════════════════════════════════════════════════════
  ⚠️ SOLUCIÓN DE PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════

❌ PROBLEMA: "Python no se reconoce"
✅ SOLUCIÓN:
   1. Instala Python desde python.org/downloads
   2. MARCA "Add Python to PATH" durante instalación
   3. Reinicia tu computadora
   4. Ejecuta SETUP.bat nuevamente

❌ PROBLEMA: "Docker no está corriendo"
✅ SOLUCIÓN:
   1. Instala Docker Desktop
   2. Abre Docker Desktop
   3. Espera a que inicie (ícono de ballena en bandeja)
   4. Ejecuta SETUP.bat nuevamente

❌ PROBLEMA: "Puerto ya en uso"
✅ SOLUCIÓN:
   1. Cierra otras aplicaciones
   2. O reinicia tu computadora
   3. Ejecuta RUN.bat nuevamente
   4. O usa puerto diferente: streamlit run app.py --server.port 8503

❌ PROBLEMA: "Módulo no encontrado"
✅ SOLUCIÓN:
   1. Ejecuta SETUP.bat nuevamente
   2. O manualmente: pip install -r requirements.txt

❌ PROBLEMA: "No abre en navegador"
✅ SOLUCIÓN:
   1. Abre manualmente: http://localhost:8501
   2. O intenta: http://127.0.0.1:8501
   3. Verifica firewall

🔍 DIAGNOSTICAR PROBLEMAS:
   → Ejecuta: CHECK_SYSTEM.bat
   → Te dice exactamente qué está mal

  📈 CÓMO FUNCIONA EL MACHINE LEARNING
═══════════════════════════════════════════════════════════════

ALGORITMO: Random Forest Classifier

DATOS DE ENTRENAMIENTO:
   📊 1,465 productos reales de Amazon
   📅 Categorías: Electrónica, Computadoras, Oficina, etc.

CARACTERÍSTICAS (INPUTS):
   1. rating - Calificación del producto (1-5)
   2. rating_count - Número de reseñas
   3. actual_price - Precio en rupias
   4. category - Categoría codificada

PREDICCIÓN (OUTPUT):
   ✅ is_successful = 1 (Exitoso)
   ❌ is_successful = 0 (No exitoso)

PRECISIÓN:
   🎯 ~85% de precisión general
   🎯 83% en Computadoras y Accesorios
   🎯 100% en Productos de Oficina

CÓMO SE DEFINE "EXITOSO":
   rating >= 4.0 estrellas AND rating_count >= 50 reseñas
