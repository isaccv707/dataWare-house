═══════════════════════════════════════════════════════════════
  🎯 QUÉ HACE ESTA HERRAMIENTA
═══════════════════════════════════════════════════════════════

Esta es una herramienta potenciada por IA que predice si un
producto será exitoso en Amazon. Usa Machine Learning para
analizar:

   ✓ Calificaciones del producto
   ✓ Número de reseñas
   ✓ Punto de precio
   ✓ Categoría del producto

Dos Aplicaciones Incluidas:

   1️⃣  Predictor de Éxito de Productos
       Para productos que ya tienen reseñas de clientes
       
   2️⃣  Asesor de Emprendedores
       Para productos NUEVOS (¡no se necesitan reseñas!)
       Solo ingresa precio + categoría

═══════════════════════════════════════════════════════════════
  ⚠️  ¿PRIMERA VEZ AQUÍ? HAZ ESTO:
═══════════════════════════════════════════════════════════════

Paso 1: Instalar Requisitos (solo una vez)
   ✓ Python 3.8+ → https://python.org/downloads
   ✓ Docker Desktop → https://docker.com/products/docker-desktop
   
Paso 2: Configuración
   ✓ Windows: Doble clic en SETUP.bat
   ✓ Mac/Linux: Ejecuta ./setup.sh
   
Paso 3: Ejecutar
   ✓ Windows: Doble clic en RUN.bat
   ✓ Mac/Linux: Ejecuta ./run.sh
